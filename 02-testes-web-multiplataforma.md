# Projeto 2 — Testes web multiplataforma

## Visão geral

Plano de testes acadêmico para um site do segmento agrícola, com foco em comportamento funcional, usabilidade e compatibilidade.

## Objetivo

Verificar se os principais componentes da interface funcionam de forma consistente em navegadores desktop e dispositivo móvel.

## Estratégia

| Estratégia | Finalidade |
|---|---|
| Teste funcional | Validar ações e respostas esperadas |
| Teste de usabilidade | Avaliar clareza e facilidade de interação |
| Teste de compatibilidade | Comparar o comportamento entre ambientes |

## Cenários priorizados

1. Navegação pelo menu superior.
2. Exibição e troca de mensagens no carrossel.
3. Preenchimento do telefone no formulário de interesse.

## Ambientes

- Google Chrome
- Microsoft Edge
- Android

A combinação de três cenários com três ambientes produziu nove execuções planejadas.

## Estrutura utilizada nos bug reports

- Ambiente
- Passos para reprodução
- Comportamento observado
- Comportamento esperado
- Urgência
- Impacto
- Status

## Exemplos de riscos cobertos

- Item de navegação sem resposta ao clique
- Carrossel que não troca a mensagem corretamente
- Campo de telefone aceitando formato inválido
- Diferenças de comportamento entre desktop e dispositivo móvel

## Evidência apresentada

Este estudo de caso consolida, em formato público e navegável, o plano de testes acadêmico, os ambientes avaliados, os riscos cobertos e a estrutura adotada para documentar defeitos.

## Competências demonstradas

- Definição de estratégia de testes
- Planejamento por ambiente
- Cobertura funcional e de usabilidade
- Escrita estruturada de defeitos
- Rastreabilidade entre cenário, execução e resultado

## Natureza do projeto

Projeto acadêmico desenvolvido durante a formação em Quality Assurance.
